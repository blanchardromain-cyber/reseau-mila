# Le réseau de Mila

Animation 3D pédagogique pour la 5e, séquence 2 « Organiser un réseau numérique ».
Situation problème : **Comment créer un réseau de données ?**

Huit chapitres et un quiz final, à ouvrir depuis `index.html` (double-clic, ou en ligne) :

1. Le besoin : les topologies anneau, maillé, étoile
2. Relier les appareils : commutateur, câble RJ45, borne Wi-Fi
3. Le serveur : authentification et stockage centralisé
4. Pannes : diagnostic des pannes A à D
5. Vers Internet : modem et routeur
6. Se protéger : passerelle, pare-feu, antivirus
7. Mission maintenance : modem ou routeur ?
8. Du collège à la maison : la box Internet et le réseau numérique
9. Quiz : 25 questions corrigées et expliquées

Dans un chapitre : clic, `→` ou `Espace` pour avancer, `←` revenir, `R` rejouer le plan,
`M` couper la voix, `L` légende, `F` plein écran.
